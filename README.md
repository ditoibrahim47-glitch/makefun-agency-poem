A program that writes one short poem about agency — the power to choose and to act, whether a person's, an AI agent's, or the agency that passes between them when one acts for the other. It writes the poem to `/output/entry.txt`, byte for byte the same on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
